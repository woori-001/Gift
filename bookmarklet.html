workline 가져오기 북마크

workline.kr 화면에서 이 북마크를 누르면 전체 정산 관리(지금 + OD)와 정산내역서를 받아 사은품 검수로 바로 넘겨요.

1. 아래 파란 버튼을 브라우저 북마크바로 끌어다 놓으세요.

사은품 검수로 가져오기

끌어다 놓기가 안 되면: 북마크바에서 오른쪽 클릭 → 북마크 추가 → 이름은 아무거나, URL 칸에 아래 내용을 붙여넣기.

쓰는 방법
  1. workline.kr 에 로그인한 화면에서 북마크를 눌러요.
  2. 오른쪽 위 작은 창에서 날짜를 확인해요. 기본값은 정산예정일 = 지난주 금요일, 정산내역서 등록일 = 지난주 목~금요일이에요.
  3. [가져오기]를 누르면 사은품 검수 창이 열려요. 팝업이 막히면 주소창의 팝업 허용을 눌러주세요.
  4. 받기가 끝나면 검수 창에 로우데이터와 정산내역서가 들어가고 서버에도 저장돼요. [검수 시작]을 누르면 돼요.
